<h2 id="os_installation">1. Installing Debian</h2>

<h3 id="requirements">1. Requirements</h3>
<p>Install Debian 13 Trixie on the computer intended for the NAS. You need a network connection
and a bootable USB drive prepared with the official Debian image. Configure the firmware to boot
from USB and follow the Debian installer.</p>
<p>A computer with TPM 2.0 is recommended, either a motherboard chip or an integrated CPU TPM
(Intel PTT, AMD fTPM). Enable it in the firmware before installing Debian. In VirtualBox, add
TPM 2.0 through the virtual machine settings.</p>

<h3 id="administrator">2. Administrator account</h3>
<p>Create the local account <code>nas</code> during installation. It is intended for administration
through SSH or a monitor and keyboard, with <code>sudo</code> privileges configured by Debian.
The launcher does not use this account. The wizard installs the launcher under the separate
<code>nas-os</code> service user and creates another user for the interface's terminal.</p>

<h3 id="disk_partitioning">3. Disks and encryption</h3>
<p>Installing Debian on an encrypted disk is recommended. Choose
<strong>Guided - use entire disk and set up encrypted LVM</strong> during partitioning and place
everything in one encrypted partition: the system, <code>/etc</code>, <code>/var</code>, and swap
must be inside LUKS. Only the EFI partition and <code>/boot</code>, which contain the kernel rather
than NAS data, remain unencrypted. Do not create separate unencrypted partitions for
<code>/var</code> or <code>/home</code>, where data-disk keys and NAS data would otherwise be stored.</p>
<p>Choose a long passphrase and keep it outside the NAS. Debian requests it on the console at each
boot. Without a connected monitor and keyboard, the NAS waits at that prompt and is not reachable
over the network. Automatic TPM unlocking is not yet available. Data disks can be encrypted later
through the Disks app.</p>
<p>The entry script checks these protections. Missing protection produces a warning but does not
stop installation; the installer can decide how to proceed. The NAS records the result for a
notification, and the Disks app shows it when encrypting a data disk with an automatic key.</p>

<div class="info_note">
  <p><strong>NAS systems without system encryption or TPM 2.0</strong></p>
  <p>System encryption protects against theft of disks or the entire NAS. It does not protect
  against network access attempts or access while the NAS is running.</p>
  <p>Without system encryption, someone holding the system disk can read:</p>
  <ul>
    <li>automatic data-disk keys, network-disk passwords, and the release token, which are encrypted
    with a key stored on that disk. With TPM 2.0, the motherboard is also required: stolen disks
    alone remain protected, but theft of the entire NAS is outside that protection;</li>
    <li>the authority key that signs the NAS HTTPS certificates, allowing another computer to
    impersonate the NAS to devices that trust that authority;</li>
    <li>application data, including photo thumbnails, indexed filenames, and logs;</li>
    <li>swap, which may contain parts of memory.</li>
  </ul>
  <p>Data disks can still be encrypted through the Disks app. On an unencrypted system, a volume
  protected only by a password remains protected even if stolen with the NAS, but must be unlocked
  manually after each boot. An automatic-key volume unlocks by itself, and someone who also holds
  the system disk may unlock it.</p>
  <p>Encrypting the system later requires reinstalling Debian with encrypted partitioning, then
  reinstalling the NAS.</p>
</div>

<h3 id="installation_verification">4. Verification</h3>
<p>After rebooting, sign in as <code>nas</code>, check private-network access, and verify that
<code>sudo</code> works. Copy the wizard package to the NAS and follow the next chapter.</p>

```bash
cat /etc/debian_version
sudo -v
lsblk -o NAME,TYPE,FSTYPE,MOUNTPOINTS
cat /sys/class/tpm/tpm0/tpm_version_major
```

<p>With an encrypted system, <code>lsblk</code> shows <code>/</code> under a <code>crypt</code>
device backed by a <code>crypto_LUKS</code> partition. With TPM 2.0 enabled, the last command
returns <code>2</code>.</p>
