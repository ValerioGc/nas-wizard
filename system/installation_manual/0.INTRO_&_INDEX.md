<h1>nas-os installation manual</h1>

<p>This manual covers Debian 13 installation and guided NAS setup. Download only the wizard
package; the wizard downloads the gateway and launcher. Keep local-console or private-network
access available during setup, because the firewall is enabled immediately.</p>

<section class="package_overview">
  <h2>Release package</h2>
  <p>The <code>ValerioGc/nas-wizard</code> release contains
  <code>nas-wizard-&lt;version&gt;-linux-x64.tar.gz</code> and its <code>.sha256</code> checksum.
  The user manual describes the launcher interface and arrives with the launcher. At installation,
  the wizard copies it alongside this manual to the terminal user's home, with the installed
  launcher's version.</p>
  <div class="package_tree" aria-label="Wizard package contents">
    <div class="package_root">nas-wizard-&lt;version&gt;-linux-x64.tar.gz</div>
    <ul>
      <li><span class="package_file">install.sh</span><span class="package_note">Entry script: the only script to run</span></li>
      <li><span class="package_file">nas_os_installation_manual_&lt;version&gt;.pdf</span><span class="package_note">This manual</span></li>
      <li><span class="package_folder">packages</span>
        <ul>
          <li><span class="package_folder">pre_wizard</span><span class="package_note">Checks before setup</span></li>
