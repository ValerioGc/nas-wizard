<h2 id="after_installation">4. After installation</h2>

<p>Most settings are managed through the interface. Local tools remain available for the release
token, application catalog, updates, and removal.</p>

<h3 id="launcher_token">1. Release token</h3>
<p>Change the token in the application manager or locally through the installed launcher tool:</p>

```bash
sudo /usr/local/lib/nas-os/configure.sh
sudo /usr/local/lib/nas-os/configure.sh --clear
```

<p>The token is stored in <code>/etc/credstore.encrypted/nas-os.launcher-token</code>, encrypted
with the machine key and TPM when available. Copying it to another machine does not allow
decryption. It is not stored in the database, and the launcher only sends it to GitHub or GitLab.</p>

<h3 id="catalogue">2. Application catalog</h3>
<p>Installable applications are listed in root-editable <code>/etc/nas-os/catalogue.json</code> or
in application-manager settings. Saving a catalog through the interface overrides the file.
<code>preinstall: true</code> marks a system application that the NAS installs automatically after
the wizard.</p>

<h3 id="updates">3. Updates</h3>
<p>Use <strong>Settings > Updates</strong> to check launcher, gateway, and wizard releases. The
launcher downloads the update, backs up its database and configuration, installs it, verifies the
new launcher responds, and restarts the NAS. Failures restore the previous copy. Debian package
updates are available from the same settings page.</p>
<p>The gateway can also be updated manually from its release package:</p>

```bash
sha256sum -c nas-gateway-<version>-linux-x64.tar.gz.sha256
mkdir nas-gateway
tar -xzf nas-gateway-<version>-linux-x64.tar.gz -C nas-gateway
sudo nas-gateway/packages/gateway_installation/install.sh
```

<p>Account and session data are preserved. Before updating, keep a consistent database backup.
The gateway maintains <code>copies/gateway.db</code> beside its live database under
<code>/var/lib/private/nas-os-gateway</code>.</p>

<h3 id="removal">4. Removal</h3>
<p>To restore the machine's pre-NAS configuration, use the single script left in the wizard package
directory. It removes the token, launcher, gateway, units, permissions, databases, accounts,
catalog, backups, and application data. It then removes the NAS firewall and only Debian packages
added by NAS setup. Pre-existing packages are preserved, including packages now required by a
Debian upgrade. The installed wizard is removed last because it supplies the operating-system
restoration scripts. Data disks are unmounted and encrypted volumes are closed without deleting
their files; automatic keys remain in <code>/etc/credstore.encrypted</code>.</p>
<p>Removal requires the original system backup captured before NAS installation. Network and
service configuration is restored from that backup; Debian package upgrades are not reversed.
The terminal user created by the wizard and its home are removed. Keep any files or manuals
needed from that home elsewhere before removal. The Debian administrator <code>nas</code> and
other pre-existing users are preserved.</p>

```bash
cd nas-wizard
sudo ./uninstall.sh
```

<p>Type <code>delete</code> to confirm, or use <code>--yes</code> to skip the prompt. To remove only
the launcher or gateway while keeping its data:</p>

```bash
sudo /usr/local/lib/nas-os/uninstall.sh
sudo /usr/local/lib/nas-os-gateway/uninstall.sh
```
